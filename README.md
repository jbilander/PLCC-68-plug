# PLCC-68-plug
A PLCC-68 plug support structure created out of PCBs

Stack several of these to form a plug, the base can reside on the main PCB with THs (through-holes) and straight square 0.5 mm pins taken from a 2.0 mm pitch pinHeader.

Dimensions UNTESTED!! Added on request by Tuc
